# Decision Log: `app` Crate Architecture

| Decision | Alternatives Considered | Objections Raised | Resolution / Rationale |
|----------|-------------------------|-------------------|------------------------|
| **Threading & Event Loop** | Spawning tokio and winit on main thread. | *Skeptic*: macOS panics if Winit/Egui/Wry don't own the main thread exclusively. | **Adopted**: `tokio` runtime will be explicitly spawned on a dedicated background thread. The main thread will be strictly reserved for the `winit` event loop driving `egui`, `tray-icon`, and `wry`. |
| **Auth Webview Footprint** | Drop `wry` for footprint. | *Skeptic & Guardian*: Bundling webview engine inflates binary and memory, contradicting "small footprint". | **Rejected**: Section 5 explicitly mandates `wry` because Facepunch's Steam login page expects a specific `window.ReactNativeWebView.postMessage` bridge. We accept the `wry` footprint cost but mitigate it by destroying the webview instantly upon capture. |
| **Auth Webview UX** | Silent instant close. | *User Advocate*: Instant closing without feedback looks like a crash. | **Adopted**: The main `egui` window will intercept the auth success and immediately render a prominent "Steam Account Linked" success state. |
| **Notification Backpressure** | Standard bounded `mpsc`. | *Skeptic, Guardian, Advocate*: `notify-rust` blocks; `try_send` drops messages silently. Coalescing destroys context. | **Adopted**: We will use a bounded channel and coalesce alerts explicitly while retaining context (e.g., "Triggered: Core TC, Roof, and 1 other") instead of generic counts. |
| **State Management** | Monolithic `Arc<Mutex<State>>`. | *Skeptic*: Contention across UI and async network threads. Deadlocks or async stalls. | **Adopted**: State will be decentralized using granular channels and `tokio::sync::watch`. |
| **Security / Token Storage** | Plaintext local file (app-data). | *Guardian*: Steam auth tokens are highly sensitive. Writing them to plaintext is a critical violation. | **Adopted**: We will add the `keyring` crate to persist the Steam token securely in the macOS Keychain and Windows Credential Manager (addressing Section 12). |
| **Connection Reliability & UX** | Basic TCP streams, static tray icon. | *Guardian & Advocate*: Background process will face sleep/wake cycles. Silent failure in tray is a liability for time-sensitive alarms. | **Adopted**: The daemon engine will implement explicit reconnections with exponential backoff and ping/pongs. The tray icon state (e.g. green dot vs red slash) will dynamically mirror this connection health. |
| **Tray Click Intent** | Opens settings page. | *User Advocate*: Users click monitoring utilities to check status, not tweak settings. | **Adopted**: The default `egui` window will be a "Status Dashboard" (connection health, recent triggers, mute toggle). Settings will be a secondary tab. |
